# 頑張れ！武流！英検マスターへの道

中学中級レベルのオリジナル英語練習です。単語40問・文法50問・読解30問（短い英文10本）を、リポジトリ直下の `index.html` だけで動きます。

問題はすべてオリジナルです。特定の検定試験・団体とは関係ありません。公式の過去問、公式の音声、公式の推薦や承認はありません。アカウント、外部への通信、アクセス解析はありません。問題画面の「読み上げ」は、この端末の音声機能だけを使います。

## 記録について

解答数、正誤、まちがえた問題、苦手マークは、見ているブラウザの localStorage（キー `chugaku-step.v1`）にだけ残ります。クラウドへは送られず、ほかの端末とは共有されません。ブラウザのデータを消すと、記録も消えます。

## 手元での確認

`index.html` をブラウザで開きます。自動テストは Node.js で実行します。

```
node test.js
```

## GitHub Pages

`main` にマージしたあと、リポジトリの Settings → Pages で次を選びます。ビルド用の GitHub Actions は不要です。

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

公開URLは `https://fuusan-games.github.io/english-step4-/` です。反映まで数分かかることがあります。`.nojekyll` は、Pages がファイルを加工しないようにするためのものです。
